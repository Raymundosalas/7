# Sistema Web de Gestión de Citas – Sprint 1

## Descripción
Este repositorio contiene el desarrollo del Sprint 1 del proyecto
“Sistema web para la gestión de citas en consultorios pequeños”.

En este Sprint se configuró el entorno de desarrollo, la estructura
base del proyecto en Vue.js y la interfaz inicial del sistema.

## Objetivo del Sprint 1
- Configurar el entorno de desarrollo
- Crear la arquitectura base del sistema
- Implementar una interfaz principal funcional
- Configurar el repositorio en GitHub

## Tecnologías utilizadas
- Vue.js 3
- Vite
- Node.js
- Vue Router
- CSS

## Estructura del proyecto
El proyecto se organiza en componentes reutilizables y vistas
navegables mediante Vue Router.

## Cómo ejecutar el proyecto
1. Clonar el repositorio:
   git clone https://github.com/usuario/sistema-citas-sprint1

2. Instalar dependencias:
   npm install

3. Ejecutar el servidor de desarrollo:
   npm run dev

4. Abrir en el navegador:
   http://localhost:5173
